## 지금 상태

핏노트는 개발자의 경험을 기업 공고, 자소서, 면접 준비에 재사용하는 지원자 중심 시제품입니다.

- 경험 보관함: STAR 입력·수정, TXT/Markdown 가져오기, 태그
- 기업별 전략: 공고 텍스트와 경험의 키워드 연결, 근거 없는 항목 안내
- 자소서: 입력 경험 기반 템플릿 초안, 직접 편집, 글자 수, 버전 저장, Markdown 다운로드
- 연습실: 자체 제작 성향 설문 12개, 추리·코드 문제 6개와 해설, 기억 연습 3단계
- 면접: 프로젝트별 질문, 90초 타이머, 카메라 미리보기, 텍스트 구성 점검
- 지원 현황: 관심 기업 / 작성 중 / 제출·면접 / 완료
- 데이터: localStorage 저장, JSON 백업과 복원

현재 외부 AI 모델·사용자 계정·서버 데이터베이스는 연결하지 않았습니다. 예시 공고는 실제 채용 정보가 아니고, 예시 경험은 사용자의 실제 경력이 아닙니다. 규칙 기반 결과와 실제 AI 결과를 혼동하지 않도록 계속 표시해야 합니다.

## UI 기준

사용자가 자신의 `preference-prompt-tool` 프로젝트 분위기를 요청했습니다. 해당 프로젝트의 현재 `ui/ux` 브랜치를 참고했습니다.

- 밝은 뉴트럴 배경과 파란 강조색
- 상단에 떠 있는 캡슐 내비게이션
- 중앙의 큰 제목, 검은 선택 스테이지, 파스텔 카드 덱
- 준비할 작업 선택 → 그 작업에 집중하는 화면
- 좌우 버튼·점·방향키·드래그로 카드 선택

UI 관련 코드는 `dist/preference-ui.js`와 `dist/preference-ui.css`입니다. 핵심 흐름은 `dist/app.js`, 순수 연결·초안·검토 로직은 `dist/engine.js`에 있습니다. 기존 데이터 키는 `fitnote.v1`이며, UI 변경 중 저장 데이터 구조를 바꾸지 않았습니다.

## 실행과 검증

저장소 루트에서 실행합니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
node --test tests/engine.test.cjs
```

브라우저: `http://127.0.0.1:4173`.

마지막 검증에서 핵심 테스트 7개가 통과했습니다. 데스크톱과 390px 모바일에서 여섯 작업 화면 전환, 카드 방향키·드래그, 설명 잘림과 가로 넘침을 확인했습니다. 모바일 면접 화면의 카메라 영역이 가로로 늘어나던 문제도 수정했습니다. 실제 카메라 장비·권한 승인은 별도 확인이 필요합니다.

## 배포와 저장 주의점

GitHub 비공개 보관 저장소: https://github.com/a77315829-byte/fitnote

최초 보관은 로그인된 GitHub 웹 화면에서 진행했습니다. 이번 작업에서는 명령줄 Git 인증을 확인하고 `origin/main`을 가져온 뒤, 동일했던 양쪽 파일 상태를 대조해 `--allow-unrelated-histories` 병합으로 기존 로컬 Sites 이력과 GitHub 이력을 연결했습니다. 이후에는 기존 `main`에서 일반적인 fetch·pull·push 흐름으로 이어가면 됩니다. 강제 푸시는 사용하지 않습니다.

현재 배포: https://fitnote-career-lab.breezy-moss-5403.chatgpt.site

본인 전용 비공개 Sites이며 ChatGPT 로그인이 필요합니다. 기존 Site ID는 `.openai/hosting.json`에 있습니다. 같은 사이트를 계속 수정할 때 ID를 유지합니다. GitHub에 코드를 올리는 것만으로 Sites가 자동 배포되도록 설정한 상태는 아닙니다.

Windows에서 Sites 로컬 패키징 도우미가 WSL을 요구해 실패했으므로, 마지막 배포는 업로드한 정확한 소스 커밋을 원격 빌드하는 방식으로 완료했습니다. Git 소유권 확인이 필요한 경우 이 작업에서 만든 저장소의 정확한 경로만 프로세스 범위에서 신뢰하도록 지정했습니다. 전역 `safe.directory=*`는 사용하지 않았습니다.

브라우저의 경험·공고·자소서·연습 기록은 Git 소스에 들어 있지 않습니다. 브라우저 데이터는 앱 설정에서 JSON으로 따로 백업합니다. 비밀 키·토큰·개인 작성 기록을 저장소에 추가하지 않습니다.
