# 핏노트 (Fitnote)

개발자의 프로젝트를 기업별 지원 전략, 자기소개서, 기술 면접 연습으로 연결하는 지원자 중심 시제품입니다.

## 실행

Node 의존성 설치나 빌드 없이 실행합니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. `dist/index.html`을 직접 열 수도 있지만, 카메라·클립보드는 localhost 또는 HTTPS에서 사용하세요.

```powershell
node --test tests/engine.test.cjs
```

## 현재 기능

- 경험 보관함: STAR 입력·수정, TXT/Markdown 파일 텍스트 가져오기, 태그, 예시 표시
- 기업별 지원 전략: 공고 본문 붙여넣기, 요구 역량 키워드와 경험 근거 연결, 누락 근거 안내
- 자소서 스튜디오: 경험을 보존하는 템플릿 초안, 직접 편집, 글자 제한, 체크리스트, 버전·Markdown 저장
- 역량 연습실: 자체 제작 12문항 자기보고 설문, 추리·자료해석·코드 읽기 6문항과 해설, 순서 기억 연습
- 면접 리허설: 프로젝트별 질문, 90초 타이머, 카메라 미리보기, 텍스트 구성 피드백·기록
- 지원 현황: 기업별 4단계 관리, 마감일
- 데이터: 브라우저 localStorage 저장, JSON 백업·복원, 삭제 전 백업 다운로드

## 범위와 한계

외부 AI 모델 API, 계정·서버 데이터베이스는 연결하지 않은 로컬 프로토타입입니다. ‘AI가 분석했다’는 가짜 로딩이나 결과를 표시하지 않습니다. 공고·경험은 규칙 기반 키워드로 연결하고, 초안은 입력된 사실을 템플릿으로 구성합니다. 공고 예시와 경험 예시를 실제 채용·경력 정보로 사용하면 안 됩니다.

성향 설문은 검증된 심리검사가 아닙니다. 자체 제작한 문항 3개씩 4개 영역을 평균하며 역문항은 역산합니다. 표준점수·직무 적합도·합격 예측을 제공하지 않습니다. 면접 체크는 단어 유무를 확인하므로 사실성·기술적 정확성 검증을 대체하지 않습니다.

카메라 영상은 브라우저의 video 요소에서만 표시하며 녹화·전송하지 않습니다. 화면 이동, 탭 숨김, 페이지 종료 시 카메라를 정지합니다. 얼굴·시선·음성으로 성격·감정·고용 적합성 점수를 산출하지 않습니다.

경험·공고·답변은 브라우저에만 저장됩니다. 다른 브라우저·도메인과 자동 동기화하지 않으며, 브라우저 데이터 삭제 시 기록이 사라집니다. Google Fonts를 불러오는 네트워크 요청에는 문서 내용이 포함되지 않습니다. PDF·DOCX 자동 파싱, 실제 공고 크롤링, JOBDA 공식 검사·기출 복제는 구현하지 않았습니다.

## 파일 구조

- `dist/index.html`, `dist/styles.css`: 인터페이스와 반응형 레이아웃
- `dist/engine.js`: 근거 연결·초안·텍스트 점검 엔진
- `dist/app.js`: 화면, 입력 검증, 저장과 상호작용
- `dist/preference-ui.js`, `dist/preference-ui.css`: Preference Prompt 프로젝트의 현재 `ui/ux` 화면 구성을 참고한 카드 선택 홈·상단 캡슐 메뉴·공통 작업 화면 스타일
- `tests/engine.test.cjs`: 근거 추적, 수치 비조작, 누락 정보, 입력 경계 검증
- `docs/PRODUCT.md`: 공개 서비스 분석, 차별점과 후속 구현 방향

Sites 배포 식별자는 `.openai/hosting.json`에 보관됩니다.

## UI 방향

밝은 뉴트럴 배경, 큰 타이포그래피, 떠 있는 캡슐형 내비게이션, 검은 스테이지와 파스텔 카드 덱을 사용합니다. 첫 화면에서 작업을 고르고 ‘선택한 작업 시작’ 버튼으로 집중 화면에 진입합니다. 카드는 이전·다음 버튼, 하단 선택 점, 좌우 방향키, 좌우 드래그로 이동할 수 있습니다. 내부 도구는 상단 작업 선택 메뉴로 바로 전환하며, 기존 브라우저 기록과 데이터 형식을 유지합니다. 애니메이션은 운영체제의 동작 줄이기 설정을 따릅니다.
