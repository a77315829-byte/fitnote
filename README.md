# 핏노트 (Fitnote)

개발자의 프로젝트를 기업별 지원 전략, 자기소개서, 기술 면접 연습으로 연결하는 지원자 중심 시제품입니다.

다음 작업은 [작업 재개 메모](docs/NEXT_SESSION.md), 작성 기준과 논문·데이터셋의 적용 범위는 [근거 기반 작성 기준](docs/EVIDENCE_STANDARD.md)에서 확인할 수 있습니다.

현재 GitHub 소스는 근거 추적 기능과 서버 API 기반을 추가한 개발 중 버전입니다. 실제 AI 호출과 이번 버전의 Sites 배포는 아직 완료하지 않았습니다.

## 실행

Node.js 22.13 이상이 필요합니다. 프로젝트 의존성을 설치한 뒤 개발 서버를 실행합니다.

```powershell
npm ci
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. PDF·DOCX 추출용 자산은 개발·빌드 명령 전에 자동으로 준비됩니다. `dist/`는 생성되는 빌드 결과이며 소스는 `public/`에 있습니다.

```powershell
npm test
npm run build
```

## 현재 기능

- 경험 보관함: STAR 입력·수정, PDF/DOCX/TXT/Markdown의 브라우저 내 텍스트 추출, 프로젝트 후보 분리·검토, 문서 위치·자료 링크와 본인 확인 표시
- 기업별 지원 전략: 공고와 경험의 키워드 후보 연결, 본인이 적는 연결 이유, 공식 크래프톤 2027 인턴십 소개 요약과 확인일
- 자소서 스튜디오: 원문을 인용한 초안, 문단별 출처·변경·추가 수치 후보 점검, 당시 근거를 보존하는 버전·보고서, 출처 표시를 제외한 Markdown 저장
- 작성 기준: 여섯 기준, OPM·FActScore·ALCE·FEVER·O*NET 자료의 적용 방법과 한계 공개
- 역량 연습실: 자체 제작 12문항 자기보고 설문, 추리·자료해석·코드 읽기 6문항과 해설, 순서 기억 연습
- 면접 리허설: 프로젝트별 질문, 90초 타이머, 카메라 미리보기, 텍스트 구성 피드백·기록
- 지원 현황: 기업별 4단계 관리, 마감일
- 데이터: 브라우저 localStorage 저장, JSON 백업·복원, 삭제 전 백업 다운로드

## 범위와 한계

외부 AI의 실제 호출은 아직 연결·검증하지 않았습니다. 서버 API는 기존 경험 ID의 순서와 보충 질문만 받도록 구현했으며, 본문은 저장된 원문으로 구성합니다. 키·모델이 설정되지 않으면 실제 AI 결과를 표시하지 않습니다. 기본 초안·문서 추출·근거 점검은 AI 연결 없이 사용할 수 있습니다. 공고 예시와 경험 예시를 실제 채용·경력 정보로 사용하면 안 됩니다.

‘원문 일치’는 저장된 기록과 문자상 일치한다는 뜻이며 경력 사실 인증이 아닙니다. 수정 문장의 의미나 기술적 정확성을 자동 판정하지 않습니다. 여섯 기준은 연구를 참고해 만든 제품 정책으로, 검증된 자소서 평가 척도나 합격 예측 모델이 아닙니다.

성향 설문은 검증된 심리검사가 아닙니다. 자체 제작한 문항 3개씩 4개 영역을 평균하며 역문항은 역산합니다. 표준점수·직무 적합도·합격 예측을 제공하지 않습니다. 면접 체크는 단어 유무를 확인하므로 사실성·기술적 정확성 검증을 대체하지 않습니다.

카메라 영상은 브라우저의 video 요소에서만 표시하며 녹화·전송하지 않습니다. 화면 이동, 탭 숨김, 페이지 종료 시 카메라를 정지합니다. 얼굴·시선·음성으로 성격·감정·고용 적합성 점수를 산출하지 않습니다.

경험·공고·답변은 브라우저에 저장됩니다. AI 연결 후에도 전송할 근거와 동의를 먼저 확인합니다. 파일 원본·카메라·전체 경험 보관함은 전송하지 않습니다. 다른 브라우저·도메인과 자동 동기화하지 않으며, 브라우저 데이터 삭제 시 기록이 사라집니다. 문서의 OCR·복잡한 표 순서 복원, 실제 공고 자동 수집, JOBDA 공식 검사·기출 복제는 구현하지 않았습니다.

## 파일 구조

- `public/app.js`, `public/engine.js`: 기본 화면·저장·키워드 연결과 구성 점검
- `public/preference-ui.js`, `public/preference-ui.css`: Preference Prompt 프로젝트를 참고한 카드 선택 홈과 공통 스타일
- `public/evidence.js`, `public/evidence-ui.js`, `public/evidence.css`: 작성 기준·원문 대조·근거 보고서 화면
- `public/documents.js`, `scripts/prepare-assets.mjs`: 브라우저 내 문서 추출과 고정 버전 라이브러리 준비
- `public/krafton.js`: 공식 모집 소개를 확인한 사례 요약
- `app/api/`, `server/draft-api.mjs`: 로그인·동일 출처·동의·크기 제한과 구조화 결과를 검사하는 서버 API
- `tests/`: 근거 추적·수치 보존·서버 경계·합성 문서 추출 테스트 42개
- `docs/EVIDENCE_STANDARD.md`: 논문·공식 자료·데이터셋과 작성 기준의 적용 범위
- `docs/PRODUCT.md`: 공개 서비스 분석, 차별점과 후속 구현 방향

Sites 배포 식별자는 `.openai/hosting.json`에 보관됩니다.

## UI 방향

밝은 뉴트럴 배경, 큰 타이포그래피, 떠 있는 캡슐형 내비게이션, 검은 스테이지와 파스텔 카드 덱을 사용합니다. 첫 화면에서 작업을 고르고 ‘선택한 작업 시작’ 버튼으로 집중 화면에 진입합니다. 카드는 이전·다음 버튼, 하단 선택 점, 좌우 방향키, 좌우 드래그로 이동할 수 있습니다. 내부 도구는 상단 작업 선택 메뉴로 바로 전환하며, 기존 브라우저 기록과 데이터 형식을 유지합니다. 애니메이션은 운영체제의 동작 줄이기 설정을 따릅니다.
